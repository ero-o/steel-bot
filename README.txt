STEEL BOT - CUSTOM TICKET PANEL

1) Put your bot token in .env
   TOKEN=YOUR_REAL_TOKEN

2) Open config.js and set:
   - ticketSupportRoleId
   - logChannelId
   - partner category ID
   - reward category ID
   - support category ID

3) In terminal:
   npm install
   npm start

4) In Discord type:
   !ticket-panel

Notes:
- The GIF banner is already included.
- The icon image is already included.
- Buttons: Partner / Claim Reward / Support
- Button icons use emojis. Raw image icons are not supported directly on Discord buttons.
